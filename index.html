Privacy Policy for CrainteAI

Last updated: November 11, 2026

CrainteAI ("we", "our", or "the extension") is committed to protecting user privacy. This Privacy Policy details our practices concerning data collection, handling, storage, and transfer when using the CrainteAI Chrome Extension.

1. Data Collection

CrainteAI does not collect, harvest, track, or sell any personally identifiable information (PII), browsing history, web traffic, or contents of the web pages you visit.

2. Data Usage and Processing

  • Client-Side Operation: The extension operates entirely within your browser. Page parsing and input processing occur locally.
  • API Requests: User-initiated requests are sent directly from your browser to the Groq API endpoints using your personal Groq API key.

3. Data Storage and Retention

  • Local Storage Only: Your Groq API key, preferences, and settings are stored locally on your device via chrome.storage.local.
  • No Developer Servers: We do not operate external backend servers, logs, or databases. Uninstalling the extension immediately purges all locally stored data.

4. Data Sharing and Third-Party Services

  • Third-Party Processing (Groq API): When you perform an action requiring AI analysis, the necessary prompt/content is transmitted directly to Groq Inc. via their official API. This communication is governed by Groq's Privacy Policy.
  • No Intermediaries: CrainteAI does not intercept, log, or route your data through any proxy servers. We never sell or share user data with advertising networks or data brokers.

5. Security

Your API key remains on your machine and is only transmitted over secure HTTPS directly to Groq's API servers during active requests.

6. Changes to This Policy

We may periodically update this policy. Revisions will be published directly to this page with an updated timestamp.
