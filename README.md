## Privacy Policy for CrainteAI
# Last updated: November 11, 2026

CrainteAI ("we", "our", or "the extension") is committed to protecting user privacy. This Privacy Policy outlines our practices regarding data collection, handling, storage, and sharing when you use the CrainteAI Chrome Extension.

### 1. Data Collection
CrainteAI does not collect, track, transmit, or sell any personal identifiable information (PII), browsing history, web traffic, or content of the pages you visit.

### 2. Data Usage and Processing
All core analysis and processing performed by CrainteAI execute locally within your browser.

API Keys: If you provide your own API keys to utilize AI features, these keys are used strictly to authenticate requests sent directly from your browser to the designated AI provider endpoint.

On-Page Analysis: Any processing of webpage text or data is handled client-side in real time and is never logged or utilized for secondary purposes.

### 3. Data Storage and Retention
Local Storage: The extension uses chrome.storage.local (or standard browser local storage) exclusively to store user configurations, preferences, and user-provided API keys.

No Server-Side Storage: Because we do not operate remote backend databases or analytics servers for this extension, none of your configuration data or keys are stored externally. You retain full control: removing the extension immediately wipes all locally stored data.

### 4. Data Sharing and Disclosure
We do not share, sell, rent, or transfer your personal data, keys, or browsing activity to third parties.

Third-Party Services: When an AI query is triggered using your own API key, the request payload is sent directly from your client to the third-party AI provider's API according to their terms of service. No intermediary proxy or tracking server managed by CrainteAI intercepts or retains this data.

### 5. Changes to This Policy
We may update this Privacy Policy from time to time to reflect changes in functionality or regulatory requirements. Any updates will be published with a revised "Last updated" date.
